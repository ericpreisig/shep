## Architecture
Resolve AI through the settings-driven provider. Reuse existing repositories, JSON persistence patterns, executor stream and feature lifecycle use cases. TypeSpec owns new domain contracts. The mind map is a projection of project tasks, not a dependency graph.

## Security Considerations
Never print authentication tokens. Validate dependency scope, cycles, map references and correction input. Do not launch another writer until the previous worker has stopped.

## Performance Implications
Persist the last usable map. Debounce regeneration and fingerprint feature input; a single in-flight generation per project coalesces concurrent requests. Bound model inputs while always preserving exhaustive membership.
